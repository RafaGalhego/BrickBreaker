## 📖 Sobre o projeto

Este é um jogo inspirado no clássico *Brick Breaker*, desenvolvido como trabalho para a disciplina de **Técnicas de Programação**. 

O jogador controla uma barra na parte inferior da tela para rebater uma bola e destruir todos os blocos, acumulando pontos. O jogo termina quando a bola cai (Game Over) ou quando todos os blocos são destruídos (Vitória).

O projeto utiliza **Java Swing** e **AWT** para a interface gráfica, aplicando conceitos de **Programação Orientada a Objetos** (POO), tratamento de eventos, animação com `Timer` e renderização em tempo real.

## 🎮 Funcionalidades
- **Movimento da barra** com as teclas esquerda e direita
- **Sistema de pontuação** – blocos das linhas superiores valem mais pontos
- **Efeito de partículas** (poeira) ao destruir blocos
- **Tela de Game Over** – quando a bola ultrapassa a base
- **Tela de Vitória** – quando todos os blocos são destruídos
- **Tema visual de "construção/obra"** com:
    - Faixas amarelas e pretas
    - Textura de parede no fundo
    - Placa de pontuação estilo obra

## 🚀 Como executar

1. **Clone o repositório** (ou baixe os arquivos):
    - git clone https://github.com/RafaGalhego/BrickBreaker.git

2. Acesse a pasta do projeto
    - cd BrickBreaker

3. Compile todos os arquivos Java
    - javac -d bin src/*.java

4. execute o jog
    - java -cp bin Main

## Tecnoclogias utilizadas 

- Linguagem de programação: Java 17
- Interface gráfica: Swing
- Eventos: AWT
- Controle de versão: Git Bash
